========================================
   ATLANTIS ANALYST - DEMO VERSION
========================================

WYMAGANIA:
- Node.js (https://nodejs.org) - zainstaluj wersję LTS

JAK URUCHOMIĆ:

Windows:
  1. Zainstaluj Node.js
  2. Kliknij dwukrotnie: START-Windows.bat
  3. Otwórz przeglądarke: http://localhost:8080

Mac / Linux:
  1. Zainstaluj Node.js
  2. Otwórz terminal w tym folderze
  3. Uruchom: ./START-Mac-Linux.sh
  4. Otwórz przeglądarke: http://localhost:8080

ALTERNATYWNIE (bez Node.js):
  Wrzuć zawartość tego folderu na dowolny hosting
  (Netlify, Vercel, GitHub Pages, dowolny serwer HTTP)
